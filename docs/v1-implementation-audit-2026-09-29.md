# JiawenLex v1 实施核对与本轮修复

更新：2026-09-29。以已约定的 v1 方案、当前代码和线上只读检查为依据。这里的“代码已具备”“配置已存在”“真实流程已验收”是不同状态；旧检查记录保留为当时的证据。

## 本轮修复

| 问题 | 修复 |
| --- | --- |
| 写作／口语在服务器保存后误报失败 | 服务端已原子保存练习与复盘快照，网页不再重复直接写受保护的复盘表。数据库确认成员没有该表的写入权限。 |
| 旧写作草稿被提交到最新题目版本 | 提交保留草稿记录的原题版本，复盘仍对应开始作答的原题。 |
| AI 的余额、权限和密钥错误被统一提示遮住 | 保留具体原因；练习页持续显示反馈失败说明，原始作答继续保存。 |
| 服务商配置变化后发送提示仍显示旧服务商 | 提交前读取最新配置；服务端校验用户确认的服务商、业务空间与配置更新时间。变化时先拒绝发送，不预留费用。旧页面需刷新。 |
| 重试缓存跨配置复用 | 缓存包含题目版本、服务商、空间、配置版本和语言，避免复用另一份配置的反馈。 |
| 转写费用使用整段练习时间 | 独立记录真实录音时长；成功转写后优先使用服务商报告的音频时长更新估算。服务商账单仍是最终依据。 |
| 录音启动失败清空上一份内容 | 成功启动后才重置；启动互斥，异常停止麦克风；录音达到一小时自动停止。 |
| 取消转写仍上传临时录音 | 在上传前确认；重新录音时清理不用的旧上传。用户主动选择保留原音时仍可只保存录音。 |
| 首页把完成的练习当成续作 | 只选择仍可访问且处于进行中的答题记录。 |
| 跳过任务仍占用计划时长 | 保留跳过记录，重新规划与首页／计划页时长均不再计入跳过任务。 |
| 计划页多设备修改覆盖已变化任务 | 只更新变更字段，并校验原状态、原日期；冲突后刷新提示。手工添加防重复，默认日期使用个人时区，并校验空日期与分钟数。 |
| 超过 API 默认行数后少加载词汇和历史 | 按 ID 游标逐页读取可见数据，继续使用原有权限策略。 |
| 后一条通知被前一条的计时器提早清除 | 新通知先取消旧计时器，离开时清理计时器。 |
| 清理超时、计数和临时录音遗漏 | 每类分批处理，达到运行时间预算返回 partial；计数按实际变更；清理无练习／转写任务引用且超过 24 小时的应用临时音频。 |
| 转写任务过期误删仍在一年保留期的录音 | 删除任务前检查练习引用，有效练习仍引用的录音由练习保留期管理。 |

清理改为每六小时执行一次（UTC 00:15、06:15、12:15、18:15；北京时间 08:15、14:15、20:15、02:15），让短批次有多次补处理机会。提醒仍每十五分钟检查一次，用户提醒默认关闭。

临时音频清理只处理应用生成的“用户 UUID／文件 UUID.webm 或 .m4a”路径；先分页收集，再检查引用与删除，避免删除导致偏移分页漏项。未提交且上传超过一天的录音属于临时文件；本机录音仍保留在原页面。文件恢复只恢复有效资料或练习引用的附件，孤立临时文件不恢复。

## 托管扩展权限的复核细节

pg_net 的对象由 supabase_admin 拥有。曾执行收紧权限迁移，但随后 ACL 复核确认，项目 postgres 角色的 REVOKE 没有撤销系统角色授予的权限；迁移返回成功不能等同于授权变更成功。迁移已在仓库保留并注明这一托管限制，便于其他环境维护。

当前网页 Data API 对 net schema 返回 HTTP 406 / PGRST106，未开放网络队列表；目录检查也没有发现成员可执行、调用 net 网络函数的 public 函数。官方说明托管项目的 net 默认授权不表示浏览器可以读取请求队列。维护时不要把 net 加入暴露 schema，也不要创建成员可调用的通用 SQL／网络转发函数。参见 [Supabase pg_net 权限说明](https://supabase.com/docs/guides/database/extensions/pg_net#permissions)。

顾问的 pg_net 位于 public 提示仍在：该扩展不能直接改 schema；重新安装会移除请求队列和历史响应，需在维护窗口确认队列为空再处理。当前未删除或重装扩展。参见 [官方排查说明](https://supabase.com/docs/guides/database/extensions/pg_net#troubleshooting)。

泄露密码保护仍未启用，应按 Supabase 当前计划支持情况决定；本轮没有开通付费服务。参见 [密码保护说明](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)。
