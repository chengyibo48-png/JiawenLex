- 31 项自动测试通过：学习算法 10 项、加密草稿 5 项、数据库总测试及 8 项子测试、设置状态与批注定位 7 项。
- 数据库测试完整执行全部迁移及原有邀请、隔离、分享、撤销、成员移除回归脚本；模拟 Auth/Storage 表与角色。
- 加密草稿测试覆盖基础版本、旧响应条件清理、冲突副本、跨标签密钥竞争和快速连续写入。

## 继续优化

- 退出先等待当前加密暂存并检查提交/录音状态；返回题组、导航和退出都会提示未提交答案或口语内容，取消后保留输入。
- 返回题组保留当前科目；录音期间限制计时模式切换；页面关闭后才获得的麦克风流立即停止。
- 设置页定期刷新保留正在编辑的字段；保存 AI 偏好只更新开关与预算；保存按钮防重复提交。
- 首页练习数量及规则计划趋势只统计本人的练习，不把朋友分享的练习算入。
- 写作批注展示原文高亮与对应建议，支持重复/交叠引用；无法定位的引用明确提示，不伪造定位。手机切换“作答／批注”。仅批注组件已用自创样例验证，真实 AI 返回仍待验证。
- 退出与练习详情采用原生弹窗，支持正反向 Tab 循环、Escape 取消和关闭后恢复焦点；退出提示默认聚焦取消。
- 浏览器验证设置修改在语言切换后保留，AI 偏好单独保存不会覆盖未保存昵称/时区；阅读返回和退出提示取消后答案保留。
- 新批注区域的 WCAG A/AA 自动检查：0 违规、0 待人工判定；390px 宽度无横向溢出。

## 待完成服务与恢复流程补齐

- 备份先上传、下载解密、校验长度与 SHA-256，并检查 pg_restore 可读性，再写 verified 标记、淘汰旧快照。任何校验失败均不能淘汰已有恢复点；检查对象批量删除的逐项错误。
- 恢复必须使用不同 Supabase 项目、匹配的数据库连接与固定快照。先建立空的应用表及权限，只从 dump 白名单导入应用与 Auth 账号数据；跳过托管 schema 重建、旧会话、平台 Vault 和 cron。
- 删除记录重放同步变更共享材料所有者与附件命名空间，保存私有恢复映射；已注销账号不能从旧快照复现。原文满一年删除、摘要保留，即使快照早于清理任务也生效。恢复文件前检查删除记录指纹，变化时要求重新重放。
- 一年草稿清理使用 updated_at 条件，避免删除扫描后刚编辑的内容；删除记录带同一条件。资料/练习先检查附件清理，再删除数据库记录，清理失败可重试。注销成功后清除该账号的本机草稿与冲突副本。
- 转写区分整体任务成功与文件子任务失败，校验结果 URL 和内容。先持久化成功转写再清理临时录音；失败清理由后续查询或定时任务补做。练习保存失败后，同页面重试复用已收到的 AI 反馈。
- DeepSeek/Qwen 文本请求显式关闭思考模式，避免 JSON 模式不兼容；异常响应不伪造反馈。计费 token 只接受有效非负整数。
- 提醒使用当地日期与单次预约，区分重复预约/数据库错误，失败发送释放预约并返回失败状态；连接有超时，拒绝向用户发送 localhost 链接。cron 使用 Vault 预检、事务和 65 秒请求超时。
- 新增管理员服务配置状态、本机 services:check、代理包装器，以及 [详细配置指南](service-setup.md)。状态明确区分配置存在与真实验收。
- **49 项本机检查通过**，包括完整迁移下的注销恢复、已授权附件转移、过期原文清除、旧会话清除、密钥撤销与新版本保护，以及加密损坏、TOC 白名单、失败备份保护旧快照、AI 返回解析、提醒并发预约与账号本机数据清理。
- 正式项目生产构建通过；专用演示会话检查了管理页配置空状态与 AI 设置，北京区域说明可见，密钥输入遮盖，390px 手机宽度无横向溢出，浏览器未记录页面错误。配置完整/缺失的具体服务行仍需使用正式管理员账号查看。
