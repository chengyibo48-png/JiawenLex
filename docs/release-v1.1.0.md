# JiawenLex v1.1.0

发布日期：2026-09-30。用户明确要求更新并同步正式网站。

## 本次更新

- 首页增加可选城市天气，支持城市搜索、刷新与失败重试；城市选择保存在当前设备，不要求定位权限。
- 修复今日任务按钮图标不可见；美化词汇、备考方法分类按钮，适配手机与深色主题。
- 扩大词汇记忆卡片，增加收藏；收藏只修改词卡标签，不更改复习日期、间隔或历史。
- 资料词库支持标签筛选，包括 AWL 学术词汇分组；显示补充释义的来源说明。
- 新增成就闪卡：每累计成功回忆 500 个不同词解锁一个里程碑。历史计数仅取可验证的确认认识事件，同词重复复习不重复计数。
- 修复练习去重逻辑：根据实际题目、文章和选项识别重复，避免相同写作说明误拦截不同题目。

## 存档与发布

- 新增成就计数表，原复习事务追加首次认识记录。保留原词卡、复习事件、学习计划、草稿、作答及用户会话；不重置、不重新安排复习。
- 迁移前保留加密本机个人记录行快照、原复习函数及资料对象清单，解密校验摘要一致；代码上一正式提交保留为回退点。未修改的 OCR 缓存和原始 PDF 不作更改。
- 本机缺少 PostgreSQL 原生归档工具，此快照不替代完整数据库归档及隔离恢复演练；本次未执行恢复操作。
- 待核验候选继续保留待处理。已授权发布的 AWL 570 张词卡及已核验资料不重复导入。
- 类型检查、生产构建及正式部署版本检查作为本次发布检查。不对用户个人记录执行写入验收。
- 发布后，后续改动继续保留本机，等待用户下一次更新指令。

## 已知边界

天气依赖第三方接口及用户网络。首张成就图已提供，后续里程碑图案待添加；公开展示素材本身不属于私密数据。触屏实机与无 WebGL2 设备仍需要单独验收。
