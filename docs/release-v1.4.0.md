# JiawenLex v1.4.0

准备日期：2026-10-05。用户已授权深度优化、授权审批功能和线上版本更新。

## 发布内容

- 有效管理员可以只读查看成员的原始资料、识别候选和页面审核状态。原件仍从私有存储生成 5 分钟链接，敏感读取响应不缓存。
- 管理员查看其他成员候选时，内容编辑、核验和发布控件只读；原有服务接口的 owner 约束保留。批量发布只枚举当前账号自己的候选。
- 组内原件分享新增上传者声明、管理员批准/退回、上传者自行开启分享的流程。批准记录不会自动打开原件；退回会关闭组内访问。
- 审批必须匹配管理员看到的声明和提交时间，防止过期页面批准新声明。分享更新再次原子检查授权状态，防止被退回的授权因并发操作恢复分享。
- 重新提交声明会关闭当前分享并进入待审。每次声明和审批通过数据库触发器在同一事务中留下历史，上传者和管理员可查看历史。
- 私人题目发布不再误要求组内分享声明。
- 修复 `pnpm backup` 包装器漏传子命令的问题，补充专用的加密数据库恢复点和受保护数据指纹核对脚本。

## 数据兼容与回归

仅应用 `20261005090000_source_rights_review.sql`。新增审核字段、历史表和触发器；已有授权声明进入待审，已有原件可见状态保留。其他未提交的迁移和用户工作不纳入本次发布。

新增回归覆盖管理员审批权限、owner 隔离、过期/重复审批、并发分享、只读历史及历史与文档的事务回滚。19 个测试文件、TypeScript 和 v1.4.0 生产构建均通过。

尚未完成逐页人工核验或音频对应检查的资料继续留待审核；本次功能发布不导入这些内容。证据和未解决问题见 `docs/local-changes/source-import-audit-20261005.md`。
