# JiawenLex：五个雅思备考平台实际体验与改进方案

调研日期：2026-09-29。对象：芒果英语、雅思团、IELTS Console、九九雅思、考满分。

## 1. 方法、证据和结论范围

本次通过独立浏览器会话进入五个网站，查看首页、导航与练习目录，点击练习入口，并在开放给游客的页面操作搜索、拼写、阅读作答及提交确认。另以 390 × 844 浏览器视口观察雅思团词汇练习和 Console 目录；这不是实体手机全面兼容性测试。

没有注册账号、购买会员、调用付费 AI 或绕过登录。评价基于这次观察，不包含流量、用户留存、真实提分效果、后台数据安全或服务长期稳定性的测量。“吸引用户”是根据交互设计推断的吸引力，不是已验证的商业数据。

本地 http://localhost:3000/ 可打开 JiawenLex 登录页；未登录内部工作台。现有能力和缺口结合实际项目代码静态阅读判断，不能据此宣称端到端运行已经通过验证。实际项目目录为 D:\.codex\JiawenLex。

## 2. 逐个平台：优势、吸引力与借鉴方式

### 2.1 芒果英语：从“学哪一科”进一步走到“练什么能力”

[首页](https://mangoielts.cn/)将目标设置、每日词汇和四科入口放在容易发现的位置。橙色品牌、圆角卡片与明确按钮让界面比较亲切；但首屏宣传区域较大，私人学习工作台应把任务优先级放得更高。

[提分工具](https://mangoielts.cn/training-tools)按科目展示同义替换、长难句、场景拼写、写作思路、搭配、Part 1 快速回答等入口。每张卡片不仅写名称，还解释训练目的与开始方式；“我的学习资产”另收个人写作复盘和口语材料。这里的工具名称与说明已看到，内部功能尚未验证。

[C21 阅读目录](https://mangoielts.cn/reading-list?scope=cambridge&book=C21)提供 Part、标题、题型和进度等选择入口，按书册到篇章分层，比直接堆出所有材料容易找到熟悉的练习。

**可迁移设计：**

- 练习页增加“题组练习 / 微训练”两个层级，微训练写清“练什么、需要多久、完成什么”。
- 第一批可做同义替换识别、听力易错拼写、写作常见错误改写；全部使用自创或有授权的材料。
- 把个人批注、错题、词表与口语素材连起来，尽量沿用现有页面，不再新开一个重复的“资产中心”。
- 今天页突出目标与一个可立即开始的动作，保留小番茄品牌的亲切感。

**不宜直接迁移：**预测或押题的效果承诺、会员营销占据首屏、同时开放大量没有内容的工具。网站将题库称为“官方”不等于我们已核实其再分发许可。

截图：[首页](mango-home.png)、[工具页](mango-tools.png)。

### 2.2 雅思团：词汇是可以操作的练习，而不只是收藏列表

[阅读词表](https://yasi.team/reading)把词、词性、中文释义与同义表达放在一起。实际搜索 resemble 后看到匹配条目，适合快速查阅阅读中遇到的替换关系。

[单词练习](https://yasi.team/vocabulary/typing)显示章节、音标、释义、双语例句、准确率和进度。输入正确单词后自动推进；隐藏提示后仍保留中文释义，形成简短的主动回忆。上一词、下一词、重开章节与静音等操作位置明确。

吸引力来自短反馈循环：一个词就能完成一次动作，有即时进度，不必先做完整题组。本次自动输入产生了异常高的速度数值，不能把这一结果当作人的打字表现或平台的学习效果。

**可迁移设计：**

- 保留 JiawenLex 的“认识 / 不认识”两档复习反馈，另增加拼写练习模式，避免混淆“选择认识”和“拼写正确”。
- 词卡可展开词性、发音、原句、场景、易错拼写与题目中的替换表达；缺项就隐藏，避免让录入变成填几十个字段。
- 从题目解析一键加入词表，保存来源材料和句子上下文；同一词多次出现时合并或提示选择。
- 以正确率、错词和到期复习为主要指标，WPM 可选，不作为雅思能力评价。
- 手机练习保留底部入口，内容单列；避免顶部完整桌面导航在窄屏被裁切。本次 390px 视口可看到其底部导航适配，而顶部导航仍有超出可视范围的部分。

同义表达应带语境说明，不能把“近义”显示成任何情况下都能直接替换。

截图：[练习](yasi-typing.png)、[手机视口](yasi-mobile.png)。

### 2.3 IELTS Console：选题信息充分，答题界面有考试操作感

[阅读目录](https://ielts-console.cloud/reading/test-list)提供关键词、Part、难度、完成状态和题型入口。每条材料显示标题、题型、题量及其他元信息，用户能先判断“是否适合现在练”。首页和目录提供主题与语言入口，左侧导航相对稳定。

本次进入“开放体验”，实操了双栏阅读与题目、答案输入和底部题号跳转。截图可见独立滚动区域、已答题标记和计时；提交时提醒具体未答题数量，能返回继续或确认提交。确认提交后跳到登录页，因此结果、解析、记录持久化没有验证。

**可迁移设计：**

- 练习列表增加题型、标签、未开始 / 进行中 / 已完成筛选；沿用资料库已有检索能力，统一筛选语义。
- 卡片优先显示题量、预计时间、最近练习状态和来源，减少选题前需要点进去的次数。
- 阅读页增加题号条，区分未答、已答、标记稍后；手机用紧凑题号抽屉。
- 提交前提示“仍有 X 题未答”，让用户直接定位漏答题或确认提交。
- 进入练习前说明模式、预计时长、计时规则和保存方式；对于自己的邀请制平台，事先明确登录要求。

目录的难度、练习人数属于网站展示值，本次未验证算法。JiawenLex 只有少量朋友，优先使用“材料标注难度”或“个人练习记录”，不制造群体排名或看似可靠的难度估计。Console 的手机目录基本转为单列，但长标题和整排难度按钮仍较拥挤，适合借鉴结构后简化。

截图：[目录](console-catalog.png)、[实际作答](console-reading.png)、[手机视口](console-mobile.png)。

### 2.4 九九雅思：熟悉的书册结构和清楚的完成状态

[首页](https://jiujiuen.cn/?source=cambridge_ielts)直接以书册与 Test 列表呈现内容，展示来源、A/G 类和未练习状态。对于已持有某本备考书的人，“我要做哪一本哪一套”比抽象推荐容易理解。

[地图题筛选页](https://jiujiuen.cn/exercises?question_type=map)保留书册/Test 层级，不匹配的 Part 被淡化，匹配 Part 更醒目。它不是简单把所有不匹配行移走：既保留上下文，又让用户关注相关部分。点击匹配练习出现登录窗口。

**可迁移设计：**

- 资料具有合集时，可按“合集 → 题组 → 部分”显示；没有该结构的自创资料仍可作为独立题组。
- 显示未开始、进行中、已完成，以及上次做题日期，避免只显示永久的“做过”。
- 默认紧凑列表，按合集查看作为可选模式；材料少时不必做大书封网格。
- 题型筛选可以提供“只看匹配项”和“保留上下文”两种呈现思路，首期选前者即可降低复杂度。

v1 继续仅支持 Academic 专项。GT 入口说明后续开放，不能因竞品存在 A/G 切换就显示暂无实现的 GT 题库。

截图：[首页](jiujiu-home.png)、[筛选后目录](jiujiu-catalog.png)。

### 2.5 考满分：同一份材料可以用于做题，也可以用于精听

[首页及练习入口](https://ielts-tingting.kmf.com/)按科目与细分技能组织训练。精听目录把同一材料的“精听听写”和“在线做题”并排提供，训练目的区分很直接。页面部分课程信息年份较早，不能据此判断这些课程仍在运营或内容都已更新。

[访问过的精听页面](https://ielts-tingting.kmf.com/listen?id=c4ca1r)可见句子分段与时长、单句 / 段落 / 全文 / 听写模式、播放控制和快捷键说明。登录窗口阻挡实际操作，因此这些是界面可见能力，不能宣称播放或听写功能已实测。

**可迁移设计：**

- 同一听力资料提供“做题”与“精听”，采用不同完成标准；精听完成不自动算一次题组成绩。
- 精听支持速度、A/B 重复、上一段 / 下一段、按需显示转写；题组计时模式继续避免提前泄露答案。
- 快捷键提供帮助和开关；焦点在输入框时不能截获用户正常打字。
- 错题若有对应时间段，可直接回放那一段，减少反复拖动找位置。

分段依赖材料有可靠时间戳，首期允许管理员手工标注；无时间戳时保留整段播放，不假装精确定位。做题和精听时间分开统计，避免总学习时间重复累计。v1 不增加自动批量解析或实时口语。

截图：[首页](kmf-home.png)、[登录遮罩后的精听界面](kmf-listening.png)。

## 3. JiawenLex 当前基础与真实缺口

以下来自项目代码静态阅读，主要文件为 components/views.tsx、components/practice-view.tsx、components/use-writing-draft.ts、components/annotated-response.tsx 和 lib/types.ts。

| 领域 | 已有基础 | 建议补充 |
| --- | --- | --- |
| 今天 | 任务、考试倒计时、周完成度、到期词汇；任务可打开材料 | 继续上次练习；今日任务和积压任务分层；更明确的首要行动 |
| 练习目录 | 按科目选择，材料列表展示题型/题量 | 标题搜索、题型/标签/状态筛选、最近练习与预计时间 |
| 阅读/听力 | 自由与计时模式、答案判定、历史；阅读手机文章/题目切换 | 未提交答案持久化、题号定位、漏答确认、结构化错题复盘 |
| 听力 | 标准音频播放与转写开关 | 精听模式、时间段标注、A/B 和速度、错题定位回放 |
| 写作 | 离线加密草稿、同步状态、计时提醒、反馈及文内批注 | 常见反馈主题对应到一次具体改写任务；沿用现有草稿保护 |
| 口语 | 录音、可选保存、转写/AI 流程与原文 | 一次只练一个提示、自评与可复用个人表达；避免引入实时对话 |
| 词汇 | 个人词表、搜索、测验、两档反馈与复习日期 | 从题目加入词表、语境/替换关系、场景标签、可选拼写模式 |
| 资料库 | 标题/题干/题型/标签文字检索、科目筛选、来源许可、共享审核 | 统一检索入口；可选合集与材料版本；更清晰的素材完整度 |
| 进度/计划 | 题型统计、反馈主题、规则计划与任务改期 | 复盘项进入计划、重练与首次练习分开看、按个人时间预算分配 |

明确的优先问题：阅读/听力答案目前在界面状态中，离开时提示会丢失；写作已有不同的存档机制。今天页把所有过去未完成任务按日期排出，长期积压后容易淹没当日任务。练习列表目前主要按科目及创建时间组织，资料库虽然已有搜索，但不能完全替代选题入口。

## 4. 建议的新主流程

```mermaid
flowchart LR
    A[今天：继续上次 / 开始任务] --> B[选题：题型、时长、状态]
    B --> C[练习：保存进度与定位题号]
    C --> D[提交：漏答确认]
    D --> E[复盘：答案、证据、错误原因]
    E --> F[加入个人词表或复习任务]
    F --> G[按计划重练]
    G --> H[进度：个人趋势与样本数]
    H --> A
```

这一流程中最关键的是减少用户手动搬运：做完题不必再打开记事本抄错词，再去计划页建立一个毫无关联的任务。

### 今天页建议

- 顶部保留问候、目标 7.5、考试日期；考试倒计时根据用户时区计算。
- 若存在未完成练习，先显示“继续上次”，注明科目、已答题数、保存状态。
- 今日主任务默认突出 1 个，列表先展示 3 个；可展开全部。积压另折叠，不自动把所有旧任务叠成今日义务。
- 待复习词卡显示可操作动作，例如“复习 8 个词”，数量来自实际数据。
- 计划的练习、复盘和词汇合计不超过每周 600 分钟；没有基础水平信息时不声称已算出最优四科分配。
- 番茄图标用在品牌、任务完成与友好空状态；阅读正文和听力操作保持安静，避免装饰抢注意力。

### 练习页建议

- 默认显示继续中与最近使用，随后是全部材料。筛选结果为空时给出“清除筛选 / 添加授权资料”。
- 模式说明明确：自由练习可逐题查看解析；计时练习结束统一解锁。先看过解析的再次练习标记为复习，不能与首次表现混为一谈。
- 电脑双栏可调比例，阅读与题目独立滚动；手机保留已有切换，并加已答数和题号入口。
- 不用颜色独自表达状态：已答、未答、稍后都具有文字或形状区别。
- 保存状态固定可见；提交失败保留内容，切换科目也不能丢失未完成会话。

### 复盘页建议

- 顺序：本次用时/完成情况 → 错题与标记题 → 每题复盘 → 下一个行动。
- 每题显示用户答案、可接受答案、解析、原文证据位置；听力有可靠时间戳才显示“回放这段”。
- 错误原因由用户选择：没定位、同义替换、词义、拼写、字数限制、漏答等。AI 只能给可修改的建议。
- 允许一键加入词表、加入复习任务、稍后重做；保存素材版本，管理员改题后历史作答仍对应当时的题目。
- 写作/口语继续展示反馈主题及修改建议，不制造预测分数。AI 关闭时同样能自评、备注和安排复盘。

## 5. 实施顺序与验收建议

| 阶段 | 工作项 | 可观察的完成标准 |
| --- | --- | --- |
| 第一阶段：每天能放心使用 | 阅读/听力练习会话保存 + 今天页继续练习 | 刷新/切换页面后能恢复答案、题号和模式；跨设备冲突保留版本；登出按用户确认处理未同步内容 |
| 第一阶段 | 题号条、稍后标记、漏答确认 | 一键到未答题；确认弹窗显示实际数量；计时未结束不泄露答案 |
| 第一阶段 | 练习目录筛选与卡片状态 | 按题型/标签/状态找到资料；筛选只作用于有权限内容；手机筛选可收起且不遮挡主要动作 |
| 第一阶段 | 今天页任务分层 | 今日与积压分开；主任务明确；查看全部与改期可用；不会改写已完成任务 |
| 第二阶段：完成后有复习 | 结构化复盘与词表联动 | 从错题加入词表保留上下文；重复词有合并提示；复习任务可返回对应题目 |
| 第二阶段 | 听力精听基础 | 有时间戳支持分段/重复；没有时间戳诚实降级；播放、输入和快捷键不冲突 |
| 第二阶段 | 词汇拼写与场景筛选 | 拼写反馈和“认识”反馈区分；结束显示错词；沿用现有个人复习进度 |
| 第二阶段 | 进度页增加复习视角 | 区分首次练习/重练；每个趋势附样本量；样本少时显示继续积累数据 |
| 第三阶段：内容充分后扩展 | 同义替换/改写/Part 1 等微训练 | 每个入口有真实授权内容和明确完成标准；能从反馈主题跳转对应训练 |
| 第三阶段 | 合集和材料管理增强 | 有合集的数据可层级定位；来源和许可完整；旧作答能追溯旧版本 |

这里列的是后续验收建议，本次没有执行 JiawenLex 的自动化测试、构建或修改业务代码。

## 6. 容易遗漏但影响长期体验的细节

1. **会话与练习记录分开。** 未提交是会话，提交后才生成正式记录；暂停不能被当作已完成。自由练习保存位置和活动用时；计时练习保存截止时间并提前说明后台/断网是否继续计时，恢复后不能重置倒计时。
2. **答案规范化有边界。** 空格、大小写和可接受变体按题目配置处理；拼写、单复数和字数限制不应被宽松规则吞掉。缺答案的资料标注无法自动判分。
3. **证据定位先可靠再漂亮。** 阅读段落、句子位置和听力时间段可手动标注；材料更新采用版本，避免旧批注失去对应原文。
4. **复盘任务有时长和原因。** 用户知道为什么推荐、需要多久；改期只影响未完成任务，每周预算包含复盘，不默认每天加新题。
5. **收藏、错题与词表用途不同。** 收藏是想再看，错题是本次答错，词表是词汇复习；不要用一个星标承载三个含义。
6. **浏览器功能不能假设总可用。** 音频需用户触发播放，速度/快捷键可关闭；麦克风不可用时沿用手动转写；手机软键盘不能覆盖输入和提交按钮。
7. **对小群体保持隐私。** 不公开朋友的分数、词表和弱项。仅授权资料可共享；新增会话、错因、标记和词源同样按个人隔离。
8. **新增数据沿用保存期限。** 原始作答、错误备注、原句引用和录音等纳入一年清理与注销规则；统计摘要不应携带被删除原文。备份恢复继续重放删除记录。
9. **加载与空状态要可区分。** 加载显示进度或骨架；失败给重试；材料缺失说明添加方式；服务未配置说明哪些普通练习仍可使用。
10. **AI 不阻挡学习。** 服务错误保留作答，自评与复习照常进行；保持发送范围确认、服务商说明和预算规则，不把所有微训练绑到 AI。

## 7. 总体取舍

JiawenLex 适合成为“有个人学习上下文的工作台”：打开知道做什么，中断能续做，完成后知道如何复盘，复习能回到真实错题。

值得优先借鉴的是芒果的能力拆分、雅思团的主动回忆、Console 的选题信息与题号导航、九九的完成状态、考满分的一材多练。维持邀请制、授权材料、AI 可选、Academic 首期与既有数据保护范围；完整四科模考、公开题库、GT 专项和实时口语继续不进入 v1。

以上建议不需要复制竞品页面、代码、题目或押题营销。其吸引力可以转化为适合 JiawenLex 的操作路径与内容组织方式。
