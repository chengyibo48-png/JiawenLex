# JiawenLex v1.3.2

发布日期：2026-10-02

## 更新

- 词汇按分类分批加载，增加服务器端单词/释义搜索，不需下载整个词表。优先加载最多 100 张到期旧词卡；分类共享原有复习记录。
- 报错记录从已有反馈快照读取词名，避免词表尚未加载时误显示为已删除。
- 资料词库、报错记录、成就闪卡具有独立入口；加载失败支持重试，避免误显示本轮完成。搜索明确区分当前分类与全部词表。
- 改善词汇导航、分类卡片、手机布局与深色主题；保留原番茄图标和四套成就闪卡资源。
- 练习选项获得焦点时同步当前题号；题干保留换行，单选组名称隔离，选择控件尺寸与焦点更清楚。听力只预加载音频元数据。
- 后台完整刷新间隔由 30 秒调整为 90 秒，保留前台恢复、网络恢复与保存后的更新。
- 未经原页核验的管理员批准词卡明确显示核验状态。

## 资料审视

94 份原始 PDF，10,086 页；现有 1,118 组练习、1,721 道题的结构检查未发现无效来源引用、重复题号或文档页数异常。修正审计工具对管理员批准内容的误报，分别记录批准发布与原页核验。

202 组具备来源核验状态；916 组为管理员批准发布但尚待原页核验。逐题来源覆盖之外的 7,224 页保留逐页待查清单，尚不能断定属于非练习内容或漏提取；结构审计不等于全文内容正确性证明。疑难内容不批量改为已核验。

新增听力和翻译批次仍在本机：音频内容尚未逐段核验，题号有缺漏，存储容量也不足以容纳全部配套资料；本版本不自动上传或发布该批次，不把不完整题目伪装为完整试卷。

## 数据与发布核对

只新增两个读取函数，按当前用户隔离并采用 security invoker；未更改现有数据表、材料 ID、答案、存档、复习日程或会话。发布前建立经校验的加密增量恢复点，发布后比较受保护表的行指纹。

执行类型检查、生产构建，以及隔离演示模式下的桌面/手机界面检查。线上核对版本、提交、静态闪卡资源与用户记录。没有执行测试套件，也未宣称完成登录后的全部浏览器验收。

恢复点包含数据库受保护记录及已校验基础备份引用，不包含新的 Auth 或对象存储二进制快照；本次没有执行完整灾难恢复演练。
