# JiawenLex v1.2.2

发布日期：2026-10-01。用户授权：继续优化、修复并同步线上。

## 修改

- 空多选答案不再计为已答；首页、练习目录、题号导航与提交检查使用一致的判断，拒绝非数组或无效选项的多选数据。
- 原资料的题号及连续题号在导航、题目、辅助标签与报错窗口一致显示；其他旧题保留顺序编号。
- 保留并展示原题完整答案限制文字，例如“词数和/或数字”，避免导入时丢失。
- 接入本机准备的四张成就闪卡展示素材及现有光效调整；缩略图延迟加载、异步解码，完整互动层只在打开时加载。展示资源附版本参数，避免更新后读取旧缓存。

## 数据与发布边界

无需数据库迁移、重导入或用户退出。不会重置作答会话、草稿、复习日期、成就或旧资料ID。

新一批7份PDF和145段录音继续在本机整理；缺失配套按用户要求跳过。未核验内容不能因本次软件发布而变为正式练习。私有音频存储容量及附件接入尚未完成，未声称新资料已经上线。

发布前记录独立加密应用数据恢复点，保留既有schema/Auth备份及对象存储原件；本次不称为完整恢复演练。回退代码基线为v1.2.1（cde5934）。
