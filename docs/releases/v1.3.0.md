# JiawenLex v1.3.0

发布日期：2026-10-02

## 词汇分类与加载

- 新增阅读、听力、写作、口语、学术核心 AWL、通用与其他六类，另有收藏与全部入口。沿用现有来源标签，不改写词卡。跨科目词卡可出现在多个分类，复习记录共用。
- 打开词汇页只请求分类数量；进入分类先读取 250 张，再按稳定 ID 游标加载后续词卡。不再在进入页面和恢复网络时自动读取全部 17,840 张词卡。
- 分类内保留收藏、发音、报错、逐词记忆和总览。未加载完整分类前明确提示范围，词表管理在完整加载后开放。
- 分类接口使用当前成员会话与数据库行权限；成员移除和会话撤销校验继续生效。

## 资料提取修复

- 跨页题目记录所有对应物理页及每页实际文字证据。
- 斜杠、括号和 or 答案变体保留原始答案并进入核验，不按包含格式符号的整串文字自动评分。
- 已逐页查看确认的第 5 册空白页标记为非练习原页，避免反复报缺识别内容。
- 本批 7 份 PDF 已解析 934 页，5 本听力书生成 120 个待核验题组；这些候选不等同于已完整核验或发布。缺配套 PDF/音频依照用户要求暂时跳过。没有上传本批新增音频或把未核验内容改为已核验。

## 数据保护与范围

- 新迁移只增加只读分类函数，使用 security invoker、auth.uid 与现有 RLS；不修改词卡 ID、复习安排、历史作答、草稿、存档或会话。
- 发布前生成加密恢复点；发布后对受保护表做只读指纹对比。原始文件和旧资料继续保留。
- 本次进行类型检查和生产构建；未运行完整浏览器验收。分类速度提升来自显著减少首屏读取量，未声称已测得各地区耗时。
