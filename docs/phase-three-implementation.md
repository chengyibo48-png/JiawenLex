# 第三阶段：内容充分后扩展

对应完整调研报告第 5 节第三阶段，保留前两阶段的保存与复盘流程。

## 微训练

新增“题组练习 / 微训练”层级。项目提供 3 组、12 项自编入门训练：语境同义替换、句子改写、Part 1 短答。标注为原创学习示例，供项目用户学习与修改使用，不是官方题库，没有复制竞品题目。每组明确训练目的、预计时间、内容数量、来源与许可、完成标准。

- 同义替换：按原句语境选择表达，再核对解释。统计语境选择正确数。
- 改写：写出自己的表达、阅读参考，再逐项选择“已做到 / 需改进”。参考表达不是唯一正确答案。
- Part 1：每次一个提示，先口头练习再记录回答或笔记，逐项自评。此次未添加录音、实时对话或自动语音评分。
- 拼写：链接到既有个人词汇拼写与场景筛选，避免重复建设入口。

微训练可通过资料库录入自创或已授权材料。来源、许可、解释、选择项/自评标准不完整的材料不会伪装成可用微训练。反馈主题按明确主题标签与同义标签关联到训练；没有匹配项时给出空状态，不把某个反馈当作自动诊断。

微训练草稿沿用现有本机加密、离线保存、云端版本冲突与账号隔离机制，使用独立存档位置；答案、当前步骤、参考查看状态、自评与活动用时可续用。练习完成独立保存，不计为四科题组成绩，不推算雅思分数。原始回答和自评一年后清除，统计摘要保留；注销与删除沿用删除记录和备份恢复流程。

## 合集、完整度与版本

- 资料增加可选的合集、题组、部分与排序，资料库和题组目录可在紧凑列表与合集视图间切换。筛选只使用当前有权限的资料，不创建空的虚构书册。
- 显示来源/许可、题目与训练标准完整度；独立资料保持原用法。
- 每次实际修改生成不可变的材料版本。当前材料编辑按版本比较保存，冲突保留编辑输入并提示刷新，避免覆盖另一设备的新版本。
- 版本历史按需加载，可查看旧版题目、来源和许可。所有者可把文字与题目另存私有副本，不覆盖原材料；不复制历史附件。
- 阅读/听力快照继续保留，新增版本号。写作/口语提交也保存当时题目快照；新写作草稿记录题目版本，历史作答无需依赖后来被修改的正文。

历史附件仅追踪名称与路径，不承诺原文件仍可播放。迁移前的材料和作答无法补造更早的版本历史；已有快照仍可查看，缺少版本号时明确标注未记录。
