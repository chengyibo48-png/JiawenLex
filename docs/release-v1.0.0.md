# JiawenLex v1.0.0

发布日期：2026-09-30。本次由用户明确授权审核发布及正式部署。

## 更新内容

- 资料档案核对 94 份 PDF、10,086 页的文件身份及解析覆盖；已发布题目的来源页、文章、答案模式和共享状态纳入核查。
- 新增 60 道逐页对照原图的口语 Part 1 原题，保留原书编号及跨页参考回答；明显语病、断句及不完整范例不发布。含 `weren’t allow` 的原题保留待修正。
- 修复词库翻页时旧列表仍可操作、重复报错编号误确认、当天巩固复习日期提示不准确，以及仅提交说明可能清空当前题干显示的问题。
- 词卡报错可以展开查看建议修改；问题类型和状态使用中文标签。
- 已发布原题可通过审核接口提交版本化修正，必须附当前材料版本号；过时修改被拒绝，原材料标识和历史版本保留。
- 导航和设置展示版本号；`/api/version` 返回版本、发布日期及部署提交号。

## 发布与用户存档规则

此版本之后，助手的代码、文件、迁移和资料整理默认保留本机。只有用户明确要求“更新版本/上线”才执行集中发布。

1. 本地准备、核验和回归检查；不得把 localhost 当成隔离数据库。本地开发仍可能连接正式数据库，禁止顺手写入正式题库。
2. 使用未推送的开发分支。用户要求发版时，更新 `package.json` 和 `release.json`，准备兼容迁移及明确发布清单。
3. 正式发布提交必须在 `main`，以 `release: v版本号` 开头，且与两个版本文件一致。Vercel 的 `ignoreCommand` 跳过普通开发提交；资料导入等维护脚本另外要求 `--release-version=版本号`。
4. 保留用户、练习、题目及材料版本标识。原存档继续引用原版本；不得重置题库、重建账号、重新安排既有复习或全局注销会话。
5. 验证正式版本号、发布内容、原存档及用户记录摘要。出现问题时回退代码，保留用户数据和兼容结构。

发布门禁用于减少误上线，不能替代用户授权。用户在正式站的正常作答、私人编辑、复习及既有定时任务继续运行。

Vercel 配置依据：[ignoreCommand](https://vercel.com/docs/project-configuration/vercel-json#ignorecommand)、[部署环境变量](https://vercel.com/docs/environment-variables/system-environment-variables)。该命令退出码 0 表示跳过构建，1 表示继续构建。

## 核验边界

解析覆盖不代表全部人工校对。未核对候选和疑难内容继续留在审核队列，不能一键改成已核验。无配套音频的练习明确属于听力文本训练；写作和口语参考回答不生成唯一正确答案或未经依据的分数。

本次备份核验读取并校验了已有加密快照内容，但因本机缺少 `pg_restore`，未完成数据库归档格式验证及隔离恢复演练；不能视为完整恢复验收。生产更新不执行数据迁移或删除操作。

完整资料处理数量、异常清单及发布后存档核对见本次检查报告。
