# JiawenLex v1.4.1

准备日期：2026-10-05。用户明确要求继续优化、修复 bug 后同步更新线上。

## 发布内容

- 拼写练习增加输入、下一词和总结的焦点衔接，开始按钮显示实际词数，保存时显示进行中状态。
- 拼写和精听在写入确认成功后标记已保存，再刷新列表，避免刷新问题影响已保存状态。
- 手机跳题自动收起题号面板；锁定或已提交的题目仍能获得定位焦点；稍后标记只统计当前题组。
- 纠错弹窗从问题类型开始聚焦，丢弃未提交修改前确认；拖选文字到遮罩不再误关闭弹窗，多弹窗共享滚动锁。
- 今日任务在请求开始时锁定，避免快速重复操作；相同日期不重复保存。
- 精听重设 A 起点清除旧 B 终点，保存时禁用段落切换并阻止离开；播放器和弹窗键盘操作不被快捷键截获。
- 存档冲突的已答计数复用题目答案规则，空多选不算已答；冲突处理增加即时操作锁。
- 同步静态版本文件与版本接口的元数据，修正静态文件仍停留在 v1.3.7 的问题。

## 发布边界

无数据库迁移、内容批量导入或自动核验；保留原有用户、资料、练习、草稿、版本副本和会话。不纳入已有未跟踪文件及未请求的迁移。

本轮执行类型检查与生产构建，不新增或运行测试。浏览器完整交互回归仍待隔离环境验收；上线后的版本接口与首页只读核对另存发布记录。工程交付不代表学习效果验证。
