## 计时与结果规则

- 自由练习按页面可见的学习时间计时；切换页面后继续会话时累计此前用时。
- 计时练习保存原开始时间与截止时间，切换页面、关闭页面或断网不会重新分配时间。
- 开始后锁定模式和时长；时间到时停止编辑，答案保留，由用户提交查看结果。
- 计时练习不提前显示逐题答案；听力文字稿在计时练习提交后开放。
- 用户选择重新开始或恢复副本时先保留被替换版本；计时副本沿用其原计时状态。
- 未提交会话和已提交练习记录分开；暂停 / 导航不会自动完成计划任务。
- 资料内容变化时提示旧作答可能不匹配，保留副本后才能重新开始。
- 提交失败保留答案；正式记录已写入但会话同步失败时提示继续补同步。

## 权限和部署

已在当前 JiawenLex Supabase 项目应用迁移：

`supabase/migrations/20260929001708_phase_one_practice_sessions.sql`

成员对新表仅有 SELECT 权限，RLS 要求本人、活动会话及可访问材料；没有管理员读取别人会话的策略。写入经过服务端身份、材料访问与版本检查。首次创建并发使用唯一键处理，后续更新使用版本条件避免覆盖。

后续在其他环境部署时，需要执行全部迁移后再发布前端。新表不含用户 API 密钥。删除账号继续依赖原来的认证用户级联删除；一年清理和旧备份删除重放沿用既有独立备份存储配置。未配置备份存储时，相应清理流程仍按原规则停止。

退出时检查未同步草稿和答题进度，可选择保留或清理；清理选择也删除该待同步条目的本机冲突副本。注销继续清理全部个人本机存档。已同步会话可在再次登录时从云端恢复。
