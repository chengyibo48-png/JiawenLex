# 第二阶段：完成后有复习

依据完整竞品报告第五节的第二阶段实施，保留第一阶段会话保存、题号导航与今天页。

## 功能

- 阅读、听力提交通过服务端重新判分，事务内核对材料版本并保存个人题目快照。复盘按错题与标记题优先，显示个人答案、可接受答案、词数限制、解析及可核对的原文证据；材料变更后历史记录仍对应旧题。旧记录无快照时明确提示。
- 用户选择错因、记录备注；版本冲突提示刷新，保留正在输入的内容，不静默覆盖。复盘加入词表保留原题/证据来源；重复词需确认并选择既有词条，保留释义与间隔。词汇来源可跳回具体原题。
- 复盘任务绑定练习和题目，今天页/计划页可回到该题。周预算包括复盘；预算已满提示改期或调整。相同未完成复盘任务不重复添加。
- 听力独立精听入口：变速、人工分段、上一段/下一段、A/B 循环、文字稿开关、默认关闭的快捷键。时间戳播放前核对音频时长；未标注时使用整段音频。精听只统计页面可见时实际播放的用时，不重复计入答题用时，不生成正确率；进行中的计时答题需先提交。
- 词汇标签/场景筛选作用于卡片、释义测验与新拼写练习。拼写结束显示错词，可再次练习，统计独立于“认识/不认识”。不上传逐字拼写答案。
- 进度区分首次、重复、看过答案/文字稿后的复习、模式未知的旧记录。每个题型显示样本量，至少两次/十题才展示统计趋势。用时明确是按题数分摊的估算，写作/口语仅展示重复反馈主题与样本数，无预测分数。

## 数据与权限

新增 `attempt_reviews`、`vocabulary_sources`、`spelling_sessions` 均只有所有者可读。服务端鉴权、检查活动账号及材料权限；分享练习不会分享题目快照、个人错因或词源。复盘和词源随原始作答一年清理、注销/删除练习时级联删除。统计保留。

备份包含新表，兼容不含新表的旧备份；恢复再次清理已过期/已清除原始内容的复盘与词源，沿用删除记录重放。新复盘快照保留原音频路径，只在材料仍可访问且附件未替换时提供证据回放。

## 本轮边界

没有复制竞品题库。人工证据与分段需管理员或资料所有者填写；没有材料时保持空状态。精听与拼写的未完成过程不作为已完成记录；精听离开时提示丢弃用时。复盘备注手动保存，未保存时离开/关闭提示。浏览器完整验收按用户要求暂缓，未执行自动化测试或恢复演练。云端新增迁移与静态编译结果见本轮交付说明。
