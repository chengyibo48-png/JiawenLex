# JiawenLex：AI 服务逐步配置

更新：2026-09-29。先配置 DeepSeek 文本反馈，再配置阿里云百炼录音转写。普通练习不依赖 AI。

## 第一阶段：DeepSeek 文本反馈

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册并登录。这是 API 服务账号；API Key 不是账号登录密码。
2. 在平台导航中找到 **API keys / API 密钥**。点创建密钥，名称填 **JiawenLex**，确认后复制完整密钥。只复制密钥本身，不加引号、变量名或空格。不要发到聊天、截图或 GitHub。
3. 打开 [JiawenLex](https://jiawen-lex.vercel.app)，登录后进入 **设置 → AI 服务与预算**。
4. 在 **文本反馈** 中选择 **DeepSeek**，将刚复制的密钥粘贴到 **API Key** 输入框，再点 **保存密钥**。提示“已加密保存”后输入框会清空，这是正常的；密钥不会回显。
5. 点 **检查连接**。这个操作只查询模型信息及可用余额状态，不发送作文或录音，也不生成文本。通过后仍需一次实际提交确认生成效果。
6. 如果提示余额不足，先在 DeepSeek 平台查看账户情况。是否充值及金额由你自行决定；本项目不自动充值，也不承诺注册即有免费额度。尚未决定时保持 AI 关闭。
7. 准备使用时，在 **月度预算（人民币）** 填一个正数，例如 **10**；勾选 **启用 AI 反馈与转写**，点 **保存 AI 开关与预算**。
8. 在资料库添加自己的写作题，进入该题写作练习，输入一段自己的短作文。确认发送窗口显示 DeepSeek 与将发送的内容，主动提交后查看批注和预算记录。仅保存或检查密钥不计为真实生成验收。

当前文本模型为 deepseek-flash，关闭思考模式，反馈提供改进建议，不生成雅思分数。接口与价格依据 [模型价格](https://api-docs.deepseek.com/quick_start/pricing/)、[模型列表](https://api-docs.deepseek.com/api/list-models/)、[余额查询](https://api-docs.deepseek.com/api/get-user-balance/)。价格可能变化，以服务商账单为准。

## 第二阶段：百炼录音转写

1. 打开 [阿里云百炼](https://bailian.console.aliyun.com/)，注册并登录。按控制台要求完成实名认证和服务开通；先查看费用和免费额度，再决定是否使用。
2. 当前 JiawenLex 接入 **华北2（北京）**。在百炼选择北京地域，选择一个业务空间，创建该空间的 **按量付费 API Key**。不要使用 Coding Plan / Token Plan 专用 key；其他地域的 key 不能混用。
3. 在业务空间详情复制 **Workspace ID**，它不是 APP ID、账号 ID 或密钥。Workspace ID 和 key 必须属于同一北京业务空间。
4. JiawenLex **设置 → 录音转写**：分别填写 **北京业务空间 Workspace ID** 和 **API Key**，点 **保存密钥 → 检查连接**。模型为 paraformer-v2；这一步查询模型信息，不上传录音。
5. 保持预算已保存、AI 已开启。到口语练习录制约 10 秒英语，选择是否保留原音，再确认发送。看到转写结果后确认文本反馈是否也正常；录音转写和文本反馈使用分别保存的配置。
6. 若希望文本反馈也由百炼提供，在 **文本反馈** 选择 **阿里云百炼 Qwen**，填写北京 Workspace ID 和按量付费 key，再单独保存并检查。仅改变下拉选项不会改变服务端实际调用的配置。

依据：[获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)、[Workspace ID](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)、[地域与端点](https://help.aliyun.com/zh/model-studio/regions)、[模型列表](https://help.aliyun.com/zh/model-studio/list-models)、[录音文件转写](https://help.aliyun.com/zh/model-studio/non-realtime-speech-recognition-user-guide)。

## 费用与隐私

- 每位成员自行创建服务商账号并在个人设置保存 key，无需修改 Vercel 或 GitHub 环境变量，也无需重新生成网站的加密密钥。
- 费用由服务商账户结算。JiawenLex 按用量估算费用并在接近预算时提示，达到预算后再次请求确认；应用预算不是服务商账单的硬性上限。
- 百炼当前是否有免费额度、有效期及免费额度用完停止功能，要按你的控制台和所用模型核实。不要把一种模型的免费限制当作其他模型的限制。参阅 [官方价格与额度](https://help.aliyun.com/zh/model-studio/model-pricing)。
- 服务端调用并加密保存密钥，网页不回显已保存的密钥。管理员界面没有查看其他成员密钥的入口。连接检查不发送学习内容，作文和录音在你确认提交时发送。
- 请求已明确被拒绝，例如密钥无效或余额不足，该次调用不计入应用费用估算；超时或异常响应可能已产生费用，应用会保留保守估算，服务商账单是最终依据。

## 常见提示

| 提示 | 处理 |
| --- | --- |
| 新输入的密钥尚未保存 | 点“保存密钥”，再点“检查连接”。 |
| 当前选项尚未保存 | 如需切换，填写当前服务商的 key 并保存；实际调用仍使用旧配置。 |
| API Key 无效或已撤销 | 到对应平台创建正确类型的 key，完整复制后重新保存。 |
| 余额不足 | 查看服务商账户，决定是否充值；不使用时关闭 AI。 |
| 服务商拒绝访问 | 百炼核对北京地域、同一业务空间、按量付费 key 和模型权限。 |
| 配置已变化 | 可能在其他设备更换了 key，刷新设置后重新检查。 |
| 无法解密已保存密钥 | 联系维护者确认线上加密配置保持一致，或重新保存个人 key。 |
| 请求过于频繁或服务暂不可用 | 稍后重试；原始作答保留。不要为绕过错误重复提交大量请求。 |
