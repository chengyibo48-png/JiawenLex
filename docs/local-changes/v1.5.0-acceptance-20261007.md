# JiawenLex v1.5.0 验收与发布准备

日期：2026-10-07。用户授权按 v1.5.0 计划实施并统一上线。

## 本轮改动

- 今天页优先展示有实际学习行为的未完成练习，继续练习默认三条；任务按行锁定，分别显示计划时长、已记录时长和完成情况。
- 练习列表补充科目、题量、核验和音频信息；移动端材料切换保留位置。听力播放集中展示倍速、循环及失败重试，重试保留播放设置。
- 提交后直接接收权威记录，区分写入成功但刷新失败，避免误导用户重复提交；提供复盘、反馈和返回今天入口。
- 复盘按证据、答案、备注、后续行动组织。备注保存即时合并对应记录，保留其他题目未保存输入；跨设备冲突展示最新内容并由用户选择。
- 加词查询同名词并允许合并，保留复习进度；排期返回权威任务，已有排期展示日期和计划入口。未核验题目不展示误导性判分。
- 统一空状态、区域错误、加载状态、青绿视觉和浅深主题；调整触控目标、焦点、弹窗输入保护及减少动态效果。
- 日期按用户时区的日历日期处理；失效任务提供解释和返回入口，保存与本机存储失败保留输入。

## 接口兼容

`apiFetch` 提供兼容 Error 的结构化 HTTP 状态和响应内容。备注返回 review，加词保留 id 并增加 word/source，排期保留 id 并增加 task。已提交但后续读取失败返回 refreshRequired，前端按 ID 合并权威记录，保护未保存输入和未完整加载的词表。

复用现有表和 RPC，无新增数据库迁移，不改变资料核验状态，不自动调用付费 AI，不重置用户记录或要求全体退出登录。既有未跟踪迁移和用户文件不纳入本轮发布。

## 验收结果

- 21 个测试文件、132 项测试通过；类型检查和生产构建通过。
- 覆盖刷新失败、备注版本冲突、加词合并进度、重复排期、无效题目、日期边界、本机存储失败及重试等回归。
- 隔离本机演示环境仅配置 DEMO_MODE；数据库用例使用本机 PGlite，未使用生产账号执行写入测试。
- 浏览器走通任务、续做、提交、复盘备注、加词、排期和词汇入口；验证断网恢复及本机存储失败后输入保留与重试。
- 正常数据和空数据分别完成 128 个布局检查：8 个页面 × 4 个宽度（360/390/768/1440）× 中英文 × 浅深主题，共 256 项，无横向溢出。
- 共 64 次 axe WCAG 2 A/AA 自动检查，0 violations、0 incomplete。
- 独立演示页面使用实际 ListeningPlayer 和合成音频，验证失败重试后倍速 1.5 与循环设置保留。
- 检查键盘焦点、减少动态效果、长标题和长答案。200% 使用 CSS zoom；软键盘通过缩小视口和输入聚焦模拟，未完成实体手机软键盘和真实屏幕阅读器人工检查。自动检查不等于完整无障碍认证，测试不证明学习效果。
