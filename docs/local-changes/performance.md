# JiawenLex v1.2.1 性能优化

日期：2026-10-01。用户已授权将性能修复发布为 v1.2.1。本次无需数据库迁移或内容重导入。

## 原因及修复

- 首页和后台刷新原先读取 15 张表的全部正文，包含整个个人词表。首页现在只取到期词数；进入词汇页才取词卡，使用同一用户的内存数据，不缓存私有正文到本地明文存储。
- 词卡确认、收藏、任务完成和改期原先等待整个工作台重新加载。现在使用服务器返回的权威行更新界面；任务的 owner、状态和日期并发检查仍保留。
- 背词原先每秒筛选、排序和构建标签。现在缓存这些计算，仅在到期时间或一分钟巩固时间到达时唤醒。
- 资料库和词表管理每页 50 条，练习目录每页 40 组；搜索仍覆盖完整已加载集合，筛选后回到第一页。分页不删除或截断后台资料。
- 练习目录预建历史记录及会话索引，避免排序时重复扫描、排序全部历史。
- 练习、词汇、资料库、方法等页面代码按需加载。
- 全量行请求页长由 500 增为 1000，首批获取可见总数，避免额外的结束空请求；仍使用 id 游标，兼容较小 API 行上限及缺失 count。
- 合并并发刷新并等待队列完成；退出后的旧请求不能回填数据。30 秒权限与工作台刷新仍保留，恢复可见/联网时刷新词表。
- 演示模式保存额度不足时保留已有存档和当前内存状态，展示提示，避免页面崩溃；此变更不影响正式云端保存。

## 验证

- `pnpm typecheck`、`pnpm build` 通过。
- `pnpm test`：101 项全部通过，包含新增 8 项加载性能及数据完整性测试。
- 独立本机生产构建演示，无生产凭据：17,847 张词卡、1,300 组阅读练习。
- 初次进入词汇页约 387ms；确认记忆约 55ms；收藏约 47ms；进入资料库约 324ms。为单次本机实测，没有线上对照基准，不代表中国大陆访问延迟或真实 API 写入耗时。
- 管理词表渲染 50 条；资料库 50 条；练习目录 40 组；第二页分别从索引 50/40 开始。
- 手机 viewport 390×844：搜索找到最后一组（1299），结果 1 条；页面宽度 390，无横向溢出。
- 全新浏览器会话无页面错误；原有权限、草稿、纠错、复习日期、幂等提交及恢复测试通过。

## 后续发布验证

发布后检查正式站版本、页面及静态资源，核对核心学习记录指纹。真实用户的网络和 API 写入耗时仍需结合实际使用复测；本机演示耗时不作为线上速度承诺。

补充修复：词表请求按账号与登录代次合并；快速退出重登不会复用旧请求，旧请求完成也不会清除新请求。对应并发回归测试已加入。

补充修复：已确认的任务保存结果覆盖同次后台请求中的旧快照，防止任务完成状态短暂回退；合并只接受当前用户的任务。
