# v1.3.6 历史资料与审核流程修复

## 检查范围

- 本次只读审计：118份线上原件，1128组有来源关联的练习，1827道题；既有94份PDF的10086页解析覆盖、线上来源引用及发布结构检查没有发现异常。
- 新批223份全文解析已完成，但原页逐题核验尚未完成；未据此批量通过候选。
- 核心存档、任务、词汇进度与原练习ID保持不变；本次无数据库迁移和题目内容替换。

## 修复

1. 审核条目选择不再重新获取整批数据，避免编辑内容被刷新清空。
2. 资料列表及审核队列使用请求序号，旧筛选结果不覆盖新结果；切换页面或卸载时作废旧请求。
3. 审核队列资料目录与候选并行读取；目录接口支持includeCapacity=false，翻页不再重复请求B2容量清单。
4. 页面审核状态请求加入序号，避免快速切换显示前一页状态；待处理统计包含尚未标记的页面。
5. 词库搜索等待250ms后请求，取消过期请求，并清除过期分页总数。
6. 审核分页转换为整数，词库页数设置上限，异常输入不产生无限或小数数据库范围。
7. 资料目录接口禁止缓存；原始资料接口时限设为60秒，兼容较慢容量查询。
8. 审核加载中显示真实加载状态，避免误提示队列为空；科目、资料类型及审核状态使用中英文标签。
9. 历史说明同步8GB已启用状态。
