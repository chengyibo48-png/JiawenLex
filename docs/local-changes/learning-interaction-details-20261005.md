# 学习交互细节优化（2026-10-05，本地）

## 范围

在 `codex/post-v1-4-0` 分支完善高频学习交互。保留 v1.4.0 版本信息，不涉及数据库结构、资料发布或线上部署。

## 改动

- **拼写练习**：开始和切换下一词后聚焦答案输入框；检查后聚焦下一词按钮，结束后聚焦总结。开始按钮显示实际练习词数，空筛选显示无词可练。保存时展示进行中状态；仅完成的非空练习允许保存。
- **保存状态**：拼写统计和精听记录在写入成功后立即标记已保存，再刷新列表，避免把刷新异常当成写入失败。服务端写入失败仍保留当前练习供重试；既有刷新函数也会通过全局提示报告加载错误。
- **题号导航**：手机选题后收起题号面板；跳转优先聚焦可操作答案控件，提交后或锁定时聚焦题目容器。“稍后”数量仅计算当前题组，避免历史题号影响计数。
- **纠错弹窗**：初始焦点位于问题类型，不再直接跳至底部提交按钮。未提交内容有变化时，取消、Escape 和点击遮罩均确认是否放弃。
- **通用弹窗**：按下和点击都在遮罩才关闭，避免从表单拖选到外部导致误关；多个弹窗共享页面滚动锁，关闭其中一个不会提前解锁。内容滚动到边界时不向背景传递。
- **今日任务**：请求开始即加锁，防止快速重复操作；选择相同改期日期不重复保存。
- **精听**：重新设置 A 起点清除旧 B 终点，避免复用旧片段；保存期间禁用段落切换；播放器、表单和弹窗中的键盘操作不被全局精听快捷键截获，未加载有效时长时不执行快捷键。

## 验证边界

TypeScript 类型检查（`tsc --noEmit`）通过。本轮未运行自动化测试或浏览器写入验收，未访问生产数据库。仍需在隔离环境覆盖键盘连续拼写、移动端跳题、弹窗拖选与多弹窗、纠错放弃确认、保存后刷新异常、精听循环及快速任务操作。

工程修改不能作为提分或学习效率提升的证明。
