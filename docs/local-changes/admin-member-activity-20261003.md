# 管理员成员活动与验收进展（本机待发布）

## 用户要求与发布条件

用户明确允许管理员查看成员在线状态和各模块答题记录；2026-10-03 补充仅管理员可见、成员没有该功能界面。新功能不修改成员角色，不改写练习、词表、复习计划或草稿。

用户要求大量原页核验、完整作答、离线同步等验收完成后再更新线上。当前尚未满足完整发布条件，因此不改版本号、不推送、不部署、不执行线上迁移或内容发布；线上仍为 v1.3.7。

## 本机实现

- 管理页新增成员在线卡片、当前模块、最近心跳；每30秒发送心跳，前台90秒内显示在线，5分钟内显示最近活跃，超过5分钟显示离线。未记录显示未知。此状态不是持续注意力或在线时长证明。
- 按阅读、听力、写作、口语、微练习、词汇复习、拼写、计划分别分页，每页25条；列表只读。阅读/听力及开放回答详情展示提交作答和保存的题目版本，微练习使用提交时的单元快照。词汇认识反馈不视为客观正确率。
- 前端入口仅管理员可见；接口每次验证真实Auth会话、会话撤销及当前数据库中的角色/活动状态。普通成员403；移除的成员不可查询；撤销会话不计入在线。
- 新增 member_presence 表，仅服务端有权限。原有成员间私有数据RLS继续保留，通过明确授权的管理员服务端只读接口提供有限的答题数据。
- 不返回API密钥、密钥配置、未提交写作草稿或原始录音的访问地址。已到期清理的作答仍仅显示统计，不从快照或备份恢复原文。
- 设置中的简短数据说明向成员说明管理员可查看学习活动，不增加成员监控界面。
- 心跳仅为短期状态，不纳入备份数据恢复，避免将旧在线状态带入恢复系统；注销依赖owner外键级联删除。新增迁移尚未应用生产。
