# 词汇成就与四张镭射闪卡（本地开发）

本次使用现有 local/next-version 分支。尚未发布、推送或应用线上迁移；原有未提交的首页、学习方法、词汇收藏等变更保留。

## 设计与计数

沿用工作台暖灰背景、蓝绿强调色和已有字体。词汇页增加独立“成就闪卡”标签：简短规则、进度、收藏卡架。色彩以现有主题 token 为准；第一张图本身是视觉重点，其余界面保持安静。未解锁为灰色，已解锁可点击进入对话框。手机两列，桌面三列。

500、1000、1500……个不同单词分别达成一项成就。记会的操作定义为正式卡片中核对后“确认认识”；这是累计成功回忆数，不是永久掌握度。按大小写和空白标准化后的词去重，同词不同词义、多次复习不重复计数。猜中、浏览、发音、导入、当天巩固不计。忘记或删除词卡不撤销已经获得的成就；注销账号级联删除个人计数。历史回填只使用可验证的 known 事件，不根据 streak 猜测。

第一张使用用户提供的蓝色角色。第二张（1000 词）使用用户提供的狗狗照片，主体和地板分别成层。第三张（1500 词）使用双角色图片，两只角色组成一个主体层；第四张（2000 词）使用珊瑚色单角色图片。四张均用原图像素构成主体和独立背景，在 WebGL 预览中可观察主体视差和整卡倾斜。所有原始文件留在本地工作资料，网站使用展示衍生资源；公开缩略图已去除原图 EXIF。

## 后端

新增迁移 `20260930060000_word_achievements.sql`：独立去重表、RLS 默认拒绝浏览器写入、原复习事务内原子记录首次认识。账号隔离由受验证 API 用户身份限定；不接受客户端自报数量。成就表已加入备份恢复表列表。未来发布需按现有流程执行恢复演练。

`GET /api/word-achievements` 返回个人总数、已达成里程碑和下一阈值，禁止缓存。迁移未启用时明确返回不可用，不显示虚假零进度。回填仅涵盖仍存在的历史事件，已删除事件不可追溯。没有改动原复习时间、词表、资料或用户会话。

## 资源和发布边界

使用 layered-holo-card 自带分层处理与 WebGL2 渲染器。原图 1200×1193；生成的背景和分层辅助图 1269×1240 存在比例差异，用户已批准只校准辅助素材到原图坐标。经原图引导的遮罩修正后，主体可见像素由原图提取，不使用 AI 重画的主体颜色；原始文件 SHA-256、生成提示词和辅助素材见 `blobs/holo-first-work/`。`output-v2/validation.json` 显示原图未变、主体 RGB 来自原图且没有结构告警。全尺寸重组图已人工查看；局部边缘与生成背景仍有细小接缝，后续可继续打磨。

本地 WebGL2 预览已打开；确认资源加载、指针驱动、整卡倾斜开关、内部浮层模式及键盘按钮可用。390×844 手机尺寸和浏览器“减少动态效果”设置下卡片正常显示；无障碍扫描未发现 WCAG 2A/2AA 问题。触屏实机和无 WebGL2 浏览器仍待核验，不能据此宣称全部设备已验收。

第二张原图为 1198×2048，SHA-256 `968d4d993c9f05b730c9831a83dcbb730351244cfc36a6d21dc758d83fd4072b`。生成背景 960×1639、主体辅助图 959×1639，按近似相同比例归一到原图尺寸，原图字节和颜色不变；提示词及处理脚本见 `blobs/holo-second-work/`。`output-v1/validation.json` 报告原图未变、可见主体像素取自原图、左右接触画框且无结构告警。全尺寸合成、整卡倾斜、只保留内部浮层、390×608 手机尺寸已人工查看。毛发边缘仍略粗糙，属于当前分层工具的已知限制。第二张嵌入页在手机尺寸下完整显示，无障碍扫描未发现 WCAG 2A/2AA 问题。

第三、第四张的背景由内置图片工具从原图编辑生成，主体提取请求均收到 `moderation_blocked`。应用户坚持使用原图的要求，没有再次调用被拒绝的生成请求；改用本地 OpenCV GrabCut 与人工边界约束，从用户原图制作遮罩，再由 layered-holo-card 原管线组装。原图 SHA-256 分别为 `461bdc183ef7d760d0a76ff3d9938b75bff72cc51b4f84db73b8a2ba5e20d689` 和 `da0a4eff3251567896034086f3c0f818cafd50273a0b3f220eb846f88fdbae53`。`blobs/holo-third-work/`、`blobs/holo-fourth-work/` 中保存了精确提示词、拒绝记录、遮罩脚本、原图、输出与预览。两份 `output-v1/validation.json` 均通过原图字节、主体 RGB 和结构检查。全尺寸重组与 WebGL2 预览已人工查看：第三张局部手部与边缘略硬，第四张右脚与草地交叠区域精度有限。背景重建的颜色和细节与原图存在可见差异；不声称背景像素精确复原。

四张素材现已接入 500、1000、1500、2000 词里程碑。第三、第四张的正式嵌入页已在桌面与 390px 手机视口检查，WebGL2 正常显示，旋转控件可操作，WCAG 2A/2AA 自动扫描均为 0 项违规。本地 `next build` 编译和 TypeScript 检查通过。自动扫描不代替触屏实机检查；第三、第四张游戏截图的公开使用授权也需在发布前确认。
